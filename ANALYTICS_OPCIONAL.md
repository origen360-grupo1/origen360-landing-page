# Web Analytics — configuración posterior y opcional

**Estado:** NO configurado. Esta entrega no instala Google Analytics ni hace seguimiento de visitantes.

El material de la Semana 11 presenta Web Analytics para comprender uso, tráfico, eventos y conversiones. En esta etapa académica todavía no es necesario registrar visitantes para mostrar un avance visual.

Si el profesor lo solicita en una entrega posterior:

1. Publica primero el sitio y define con el equipo qué métricas son útiles (por ejemplo, visitas a la sección de pasaporte y consultas de ejemplo).
2. Crea una cuenta y una propiedad de **Google Analytics 4 (GA4)**; configura un flujo de datos web usando la URL pública.
3. Obtén el ID de medición de esa propiedad. No uses un código de ejemplo o inventado.
4. Antes de insertar Google Tag, revisa qué requisitos de información, consentimiento y privacidad corresponden a los visitantes del sitio. No actives el seguimiento si todavía no está definido.
5. Una vez permitido, incorpora el código que Google proporciona en el `<head>` de `public/index.html` y verifica la medición en GA4.
6. Documenta qué eventos se recopilan y para qué finalidad; no envíes nombres, códigos personales ni datos sensibles en los eventos.

**Nota:** algunos ejemplos del PDF de Semana 11 contienen pantallas e identificadores antiguos como `UA-...`; no son un ID de medición válido para las propiedades actuales de GA4. Usa la configuración mostrada por Google Analytics en tu cuenta.

Sitio oficial: https://analytics.google.com/
