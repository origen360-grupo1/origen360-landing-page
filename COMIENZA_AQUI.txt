ORIGEN360 PERÚ — COMIENZA AQUÍ (SEMANA 12)

1. Descomprime el archivo ZIP.
2. Abre WebStorm y selecciona la carpeta Origen360_LandingPage_MEJORADO (la que contiene README.md).
3. En el explorador, abre public → index.html y elige "Open in Browser".
4. Prueba el menú en una ventana pequeña. Pulsa Escape para cerrarlo.
5. Baja a "Explora un pasaporte digital": usa O360-DEMO-001 (Palta Hass) u O360-DEMO-002 (Café).
6. Si todavía no descargaste videos, verás tres portadas ilustrativas. Es normal.
7. Cuando tengas los MP4, colócalos en public/assets/videos/, con los nombres de la guía.
8. Lee GUIA_ENTREGA.md para subir las ramas a GitHub, transferir el repositorio y crear el PDF.

CARPETAS COMO EN CLASE:
- El profesor: css/index.css       → Nuestro challenge: public/assets/styles/styles.css
- El profesor: Imagenes/          → Nuestro challenge: public/assets/images/
- El profesor: js/                → Nuestro challenge: public/assets/scripts/main.js
- El profesor: videos/            → Nuestro challenge: public/assets/videos/
- El profesor: index.html         → Nuestro challenge: public/index.html

No cambies estos nombres: el enunciado exige la estructura public/assets.
La ficha demo NO verifica certificados reales ni usa una base de datos.
Los pasos de GitHub se hacen desde la cuenta del equipo; este ZIP no está publicado.
